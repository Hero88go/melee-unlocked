## Install

Download `MeleeUnlocked-0.8.89-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## Fixes

- Stability, Static Recomp: every match left a little of the game's stack in use, and a long session ended in a crash (stack overflow) while the next screen loaded. Matches no longer leave anything behind.
