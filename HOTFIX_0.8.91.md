## Install

Download `MeleeUnlocked-0.8.91-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## Fixes

- Online Teams, Source Port: every fighter showed in the red costume. Each fighter now wears the costume of their team.
- Display: the CRT shader presets now come with the game in the Shaders folder and can be picked under Video without a separate download.
- Display: a single shader file (.slang) placed directly in the Shaders folder can be picked under Video and runs as a one pass shader.
- Display: a shader preset copied without the files it uses showed a raw "path not found" error. The message now names the missing file and says to copy the whole shader pack with its folders.
- Display: border art has a soft shadow where it meets the game picture. The new Border edge option under Video switches between Soft shadow and Sharp.
