## Install

Download `MeleeUnlocked-0.8.80-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## New

- Static Recomp, Teams: a modded disc can now play online Teams when all four players run the same mod. Each player's game checks every other player's mod, and a player on a different mod or on the retail game is refused with a message. The mod's extra characters and stages work in Teams. Unranked and Party still use the retail game, and the Source Port still uses the retail game in Teams.
