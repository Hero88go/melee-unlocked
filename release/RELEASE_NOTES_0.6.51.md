# Melee Unlocked 0.6.51

Hotfix release.

- Restores separate Stable Recomp Legacy and DLSS 5 Experimental downloads.
- Stable Recomp Legacy no longer ships the unsigned DLSS5 forwarder or DLSS5 executable.
- The launcher updater selects the correct archive for the selected build.
- All packaged executables report version `0.6.51`.

DLSS 5 remains experimental and requires NVIDIA's `nvngx_dlssnr.dll` model from the driver or
user installation. No model is included in either archive.
