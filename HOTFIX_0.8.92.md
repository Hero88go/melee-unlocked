## Install

Download `MeleeUnlocked-0.8.92-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## Fixes

- Replays: the launcher's Replays page said "The playback system files are missing from this installation" and played nothing. The files now come with the release, and replays play on the Source Port.
- Mod discs: the log notes the game's object memory at each scene, and when it runs out it lists what each of the game's heaps had left, so a report shows what filled up.
