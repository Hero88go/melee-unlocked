## Install

Download `MeleeUnlocked-0.8.78-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## New

- Both engines, GameCube adapters: **Reset GameCube adapter** under **F1 > Controls** reconnects the adapter and recalibrates all four controller sockets.

## Fixes

- Source Port, credits: fixed a crash while highlighting entries on the credits screen.
- Source Port, consecutive matches: fixed a memory-handling issue that could cause a crash while loading another match.
