## Install

Download `MeleeUnlocked-0.8.94-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## Fixes

- Controllers: first native support for the Nintendo Switch Online GameCube controller over USB, with analog triggers. It needs a WinUSB driver on the controller's "Interface 1" (Zadig), the same step the GameCube adapter needs. It has not been tried on a real controller yet: if it does not respond, use Send logs.
