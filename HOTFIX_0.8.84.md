## Install

Download `MeleeUnlocked-0.8.84-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## New

- Online freezes are marked in the session trace automatically, so Send recent game logs includes them even when you did not press a mark button.

## Fixes

- Online, Source Port: no more freeze during the countdown when playing someone on Slippi Dolphin. Both games now start together.
- Graphics: the game no longer crashes at launch on graphics cards without DLSS support. It starts without DLSS instead.
- Mods, Static Recomp: a mod stage that draws a texture past the end of memory no longer stops the game.
