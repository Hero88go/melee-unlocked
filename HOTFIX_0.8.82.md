## Install

Download `MeleeUnlocked-0.8.82-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## New

- Mod mismatch messages now identify the player whose build differs and explain which files everyone needs to match.

## Fixes

- Show results screen: turning it off now goes straight back to character select after an offline match on Static Recomp.
- Static Recomp: fixed a stack overflow when returning from modded game code, including between matches.
- NVIDIA effects: fixed frame-generation inputs keeping their old size after a window resize. Driver resource errors in optional NVIDIA effects now disable the failing effect instead of stopping the game.
