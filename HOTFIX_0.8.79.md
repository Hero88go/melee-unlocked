## Install

Download `MeleeUnlocked-0.8.79-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## New

- Both engines, custom music: **F1 > Audio > Use custom music** and **Open music packs**. The `MusicPacks` folder lists every menu and stage track in `Tracks.txt`. Copy a track's path under `MusicPacks` to replace it, or put several files in a folder named after the track to pick one at random each time it starts. HPS, WAV, MP3, M4A and other formats Windows can play work. A file the game cannot read falls back to the disc track. Custom music plays only on your computer.
- Both engines, texture packs: **F1 > Video** now says that packs can replace HUD, menu and stage art, and **Open texture dump** opens the folder with the exact filenames to replace.

## Fixes

- Source Port, Big Blue: corrected where the cars and platforms keep their data, which could crash the match.
- Both engines, Slippi: the launcher and the game find your Slippi account more reliably.
- Both engines, online traces: a trace now marks the moment the two games stop matching, and `melee_port.log` is no longer replaced when the settings window opens.
