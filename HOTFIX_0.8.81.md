## Install

Download `MeleeUnlocked-0.8.81-win64.zip` from this release. Close the game and launcher, then extract it over your existing Melee Unlocked folder. Settings, saves, mods and replays stay in place. Use your own Melee NTSC 1.02 ISO.

## New

- Show results screen (F1, Game tab): turn it off to go straight back to character select after each offline match, for playing sets back to back. Works on both engines. Online matches are unchanged.

## Fixes

- Source Port, startup: fixed the game stopping at launch with "melee_game.dll loaded at ... not at 82800000".
- Static Recomp, Gecko codes: imported codes reserve game memory only when at least one is on, leaving large mods like ACE their full memory. Restart after turning on the first code.
- Launcher, NKit images: an NKit disc image is now named as such, with how to restore it to a full ISO, instead of being listed as a custom mod.
